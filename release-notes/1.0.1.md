Mindex 1.0.0 could not start on macOS and could not reach your assistant on Windows. Both are fixed.
- macOS: the app is signed again. 1.0.0 shipped without a code signature, so macOS killed it the moment it was opened — no window, no message, nothing in any log. The release now refuses to publish a build that is not signed.
- Windows: installing an assistant from the welcome screen failed with "spawn EINVAL", and an assistant that was already installed was reported as missing. Both came from the way Windows starts programs installed through npm; Mindex now starts them directly.
- Windows: the list of places Mindex searches for your assistants was being split on the wrong character, which left nothing findable by name.
- The status line while a runtime is being set up no longer breaks onto two lines.
