Setting up a folder on the welcome screen got stuck, and signing in to an assistant could not find it. Both are fixed.
- Choosing a folder that is not a vault yet asked for confirmation behind the welcome screen, where it could not be seen or clicked — the app looked frozen. The welcome screen now steps aside for that question, and closes for good once the vault is open.
- Signing in opened a terminal that could not find an assistant Mindex had installed itself, because Mindex keeps it in a private folder that is on nobody's PATH. The terminal is now given the paths it needs.
- The window is shown even when the page never reports a first paint. Until now that left the app running with nothing on screen and no error.
