Mindex is open source: an IDE for your knowledge, free, with your assistant working inside your notes.
- Everything is a plain Markdown file on your own disk — no account, no database, no export step.
- Chat beside your notes with Claude Code, Codex or Gemini CLI, on the subscription you already have.
- Set how far a question may reach — this note, this folder, the whole vault — and ask for the answer in chat, in the note, or as a Word, Excel, PDF or Markdown file.
- Interrupt an answer by sending the next message.
- A background job keeps a context file per folder current, under the name your assistant reads natively.
- Editor and source view of the same file, wiki links, backlinks, graph, typed notes, comments and local version history.
- Built-in Git, a command palette, split panes and full-text search.
- macOS, Windows and Linux. Source at github.com/gixp/Mindex under AGPL-3.0.
