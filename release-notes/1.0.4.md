Folders can be renamed, a new one asks for its name, and on Windows an empty folder is no longer invisible.
- A folder can be renamed. The sidebar offered Rename on a note and nothing on a folder, so a folder created as "Untitled folder" stayed that way unless you made a new one, dragged everything across and deleted the old.
- A new folder opens a name box in the sidebar instead of being called "Untitled folder" and left there — the same thing a new note already did.
- On Windows, a folder with nothing in it never appeared in the sidebar at all. The folder list arrived in Windows separators and was matched against a path built with forward slashes, so the whole list was discarded; a new folder only showed up once a file inside it implied the path.
- A folder page with nothing on it no longer carries a button of its own. New file and New folder sit in the top right of every folder page, and the one in the middle was the same two actions in a second place.
- A folder dragged somewhere new now tells the index it moved, so an empty one no longer lingers under its old name until the next rebuild.
